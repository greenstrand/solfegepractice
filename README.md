# Fixed Dojo

Fixed-do clef solfege drill: paced staff practice with React and SVG notation.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Check

Format, lint, typecheck, and tests:

```bash
npm run check
```

Other scripts:

- `npm run build` - production build
- `npm test` - Vitest once
